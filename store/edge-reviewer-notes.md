# Microsoft Edge Add-ons reviewer notes

Ampira replaces `edge://newtab` with its packaged `dashboard.html`. Required permissions are limited to `activeTab`, `bookmarks`, `storage`, and `alarms`. Toolbar capture reads only the title and URL of the tab on which the user explicitly clicks Ampira. Bookmark access is read-only.

Microsoft Edge does not expose the Chrome native `/_favicon/` service used by Ampira's optional `favicon` permission. Ampira detects Edge, does not request that permission during onboarding, hides the unsupported permission control, and uses its packaged icon instead. This does not affect bookmark, Feed, Reader, or website-origin permissions. Edge may also retain its own browser-shell icon for an overridden New Tab tab.

Optional website access is requested only from a user gesture and is restricted to exact origins. Optional browser search uses the supported `chrome.search` API with the user's current Edge default provider. In conversational search, bookmark-folder research and provider-native web search are separate default-off, session-only controls. Bookmark metadata remains a non-citable candidate index; only Feed or Reader passages enter answers. Web answers and cited sources are not written to IndexedDB, and selected-folder research caches small passages and metadata rather than separately extracted full text. The optional Brave key is only for fallback image search. API keys remain in `chrome.storage.local` by default. A separate default-off switch synchronizes AI/Brave keys and complete AI provider configuration through browser account sync, without additional Ampira encryption. Device consent and permissions remain local. Non-credential settings and separately opted-in reading queue, to-dos, weather city, stock watchlist, and countdowns also use browser account sync. The extension contains no remote code, analytics, advertising, payment flow, content scripts, or developer backend.

For detailed functional scenarios, use `store/reviewer-notes.md`, substituting Edge browser terminology and `edge://` internal pages. Use only synthetic data and non-production credentials during review.

Unified search uses one suggestions list from the navigation button. Optional history is off by default and user-enabled from Settings → Browser or a list action. Verify synthetic history queries, rejection, revocation and deletion during an in-flight query; history is transient and never sent to AI/Bot. Verify local-first Enter selection, URL navigation, default-provider search and returning from AI to the saved query. Factory reset revokes history access without deleting browser history.
