3. The required permissions are `activeTab`, `bookmarks`, `storage`, and `alarms`. `activeTab` is used only after the user clicks the Ampira toolbar icon to read that page's title and URL and save it to the reading queue; it does not monitor tabs, page contents, or browsing history. Reading-queue records remain local unless the user separately enables the default-off Chrome Sync switch. The extension only calls bookmark read methods. The optional `favicon` permission is requested from onboarding or Settings → Browser and can be removed there; without it, Ampira uses its packaged fallback icon. The optional `search` permission is requested from Settings → Browser or its explicit list action and uses Chrome's Search API with the user's current default provider; removing it disables the web action while retaining local search. Optional `history` is user-enabled only for local query suggestions and is never sent to AI.
