Ampira includes a local SVG subset with weight 600 and optical size 24.
Icons use FILL 0, except the saved-bookmark state which uses FILL 1.
Local changes: filenames and explicit black root fill for existing theme filters.
The push_pin symbol also has an explicit 24px viewBox for consistent scaling.
The original symbol name is retained in each SVG's attribution comment.
