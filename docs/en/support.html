Help and support

Support

Restore the browser’s default New Tab page

Open chrome://extensions in Chrome or edge://extensions in Microsoft Edge, find Ampira, then disable or uninstall it. The browser does not allow an extension page setting to remove its own New Tab override dynamically.

A news source has no content

Check source coverage and per-source diagnostics on the News page, then verify exact-domain access on the Browser page. If a source page declares a Feed on another domain, Ampira lists that exact domain and waits for your click before requesting it. Bookmarks remain available without access.

AI is unavailable

Confirm that an API key is saved, the data-transfer notice is accepted, the AI service domain is allowed, and the connection test succeeds. Ampira does not provide or proxy API keys.

Report a problem

Use the project support channel and include reproduction steps, the browser name and version, and screenshots that contain no keys or private bookmarks.
