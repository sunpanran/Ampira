資料管理

資料刪除

  1. 在「設定 → 關於 → 設定移轉」點選「恢復原廠設定」，會清除本機的 Ampira 設定、API 金鑰、授權、本機首圖、快取與使用者內容，並撤銷選用權限。瀏覽器帳號中同步的 Ampira 設定、稍後讀、待辦、天氣城市、自選股票、倒數日、金鑰與 AI 設定副本也會刪除。同步刪除會影響同一帳號的其他裝置，但不會遠端清除其他裝置獨有的本機資料。瀏覽器書籤和原始瀏覽歷史不會被修改；選用 history 權限會被撤銷，暫存的歷史搜尋結果會失效。
  2. 在設定的「資訊」頁點選「清除快取」，刪除資訊、摘要、搜尋快取與來源品質記錄。
  3. 在設定的「AI」頁點選「移除金鑰」或「移除搜尋金鑰」，會刪除本機對應的金鑰。如果金鑰同步已開啟，其他裝置也會同步刪除該金鑰。
  4. 在 Chrome 的 chrome://extensions 或 Microsoft Edge 的 edge://extensions 解除安裝 Ampira，會清除擴充功能 IndexedDB、API 金鑰與本機擴充功能儲存空間。
  5. 只想停止某項同步時，可在「設定 → 瀏覽器 → 跨裝置同步」關閉對應開關。這會刪除帳號中的該項同步副本，各裝置已收到的內容或 AI 設定仍會保留。
  6. Bot 看板：在「設定 → MCP → 連接資訊」點選「中斷連接」（總開關關閉時也可操作），刪除瀏覽器中的本機位址與配對金鑰。要清除快取與傳送記錄，可切回標準模式後恢復原廠設定。輔助服務儲存的看板、留言與去重記錄需先停止服務，再單獨刪除其資料目錄（預設為使用者主目錄下的 .ampira-mcp）。AI 用戶端中的 MCP 設定與任務也需另行移除或停止。

Ampira 沒有開發者帳號或伺服器，因此不存在需要向開發者申請刪除的雲端使用者資料庫。
