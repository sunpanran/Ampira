資料與隱私

Ampira 隱私權政策

生效日期：2026-11-08

Ampira 的單一用途是將靈感預設（Ampira）、使用者選擇的瀏覽器書籤與資訊來源整理成可搜尋的新分頁資訊看板。Ampira 沒有開發者伺服器、帳號系統、廣告或分析。

選用 AI 助手看板

AI 助手看板可分別選擇今日簡報、資訊整理和 AI 問答，未勾選項使用原有 AI 設定。天氣、待辦、資訊擷取與排序、事件和靈感由擴充功能處理；僅為所選功能提交新的助手任務。擴充功能可將有界的已授權資訊候選，或使用者主動提問匹配的資料摘錄與來源傳送至本機服務；明確要求的文章連結也可在已有網站權限內擷取。不會自動上傳整棵書籤樹、瀏覽記錄或其他 AI 應用程式的聊天歷史。簡報依日期與證據重複使用，問題只附同一對話的有限近期內容。輔助服務儲存有界任務、已傳送問題及其資料。預設不啟動模型；使用者在本機明確啟用 Codex 自動執行器後，排隊中的簡報與問題會透過目前登入的 Codex 帳戶自動產生並回填，消耗該帳戶用量。任務資料會交給 Codex，暫存結果檔案於執行結束後清理；失敗或中斷後需主動重試。擴充功能不會讀取 Codex 登入憑證或其他聊天歷史。

「接管內容」中的「資訊整理」預設不勾選，僅在 MCP 與 AI 助手看板已開啟時生效。開啟後，自動、批次及單筆資訊整理（含外文翻譯）將已授權快取中的標題與最多 2,000 字元摘錄按每批最多五筆傳送至本機服務，供已授權 AI 助手處理；不傳送 API 金鑰、書籤樹或瀏覽記錄。驗證後的摘要在本機依原文與語言重複使用。等待或失敗時不自動切換內建 AI。輔助服務儲存有界整理任務；已設定本機執行器時會使用其帳戶用量自動處理。

MCP 總開關、AI 助手看板與接管選項分別儲存，修改即時生效。開啟總開關或點擊「複製接入指令」時，從使用者操作要求 http://127.0.0.1/* 選用權限。指令包含十分鐘有效的一次性配對碼與擴充功能識別碼，由使用者主動交給可執行本機命令的 AI。長期配對金鑰由本機服務與擴充功能直接交換，不包含於指令、命令輸出或一般設定回應中；頁面不提供手動金鑰表單。

關閉總開關保留模式與配對；連線資訊可唯讀查看服務位址，也可在總開關關閉時中斷瀏覽器配對。這些操作不會刪除已傳送內容、停止獨立輔助服務或停止外部助手任務。來源權限變更會阻止不再授權的內容顯示，但無法撤回已進入外部 AI 對話的資料。

配對金鑰儲存於目前瀏覽器的 chrome.storage.local 與輔助服務的本機資料目錄，不參與同步或匯出。瀏覽器快取依服務位址與看板身分隔離。輔助服務只監聽 127.0.0.1，驗證 Host、Origin 與配對金鑰，預設將看板、留言與去重記錄儲存於使用者主目錄的 .ampira-mcp，不額外加密。已授權 AI 用戶端可能依設定將 MCP 內容傳送給模型提供商；開發者不會接收這些資料。中斷連線、恢復原廠設定或解除安裝擴充功能不會刪除輔助服務的資料目錄，需停止服務後另行處理。

處理的資料

  • 使用者選擇的書籤標題、網址與資料夾結構。
  • 使用者授權來源的公開 Feed、網頁標題、摘要、正文，以及靈感頁封面中繼資料與圖片網址。
  • 介面設定、閱讀佇列、封存、來源偏好、快取與搜尋問題；使用者透過工具列或 Ampira 卡片明確加入稍後讀的頁面標題與網址會保存在閱讀佇列中。
  • 使用者輸入的待辦事項，以及手動選擇的天氣城市、行政區、國家和座標。
  • 使用者自願設定的 AI 金鑰或選用的 Brave 圖片搜尋 API 金鑰。

用途與儲存

預設首圖使用 Unsplash（images.unsplash.com）的網路圖片，沿用下述網路首圖載入與快取規則。顯示時圖片網站會收到 IP 位址等一般網路資訊；使用者可在外觀設定中更換或關閉首圖。

Ampira 使用 chrome.storage.sync 儲存部分非憑證設定。閱讀佇列、待辦事項、所選天氣城市、自選股票與倒數日預設只保存在擴充功能 IndexedDB；使用者可在「設定 →瀏覽器 → 跨裝置同步」中分別選擇加入同步。資訊、摘要、搜尋快取、完整閱讀狀態、實用卡模式與天氣回應快取始終保存在本機。使用者選擇的本機首圖會在瀏覽器內移除原始檔案中繼資料並最佳化為 WebP，只保存在目前瀏覽器設定檔的 chrome.storage.local，不參與瀏覽器帳戶同步或設定匯出；移除、更換或解除安裝擴充功能會清除對應的本機副本。API 金鑰與 AI 服務設定預設保存在目前瀏覽器設定檔的 chrome.storage.local，儲存後頁面不會再次顯示完整金鑰。

「同步 API 金鑰與 AI 設定」預設關閉，需要另外開啟；「同步個人內容」不會開啟金鑰同步。開啟後，AI 和 Brave 圖片搜尋金鑰會與 AI 服務位址、協定、模型一起儲存至瀏覽器帳號的同步空間（chrome.storage.sync）。Ampira 不額外加密，也不設定同步密碼。各裝置需登入同一瀏覽器帳號並開啟擴充功能同步；新裝置仍需同意 AI 資料傳輸，並授權存取服務網站。

關閉金鑰同步或恢復原廠設定，會刪除帳號中的同步副本，其他裝置已收到的本機設定仍會保留。如果在同步開啟時移除某個金鑰，其他裝置也會同步刪除該金鑰。同時在多台裝置變更時，以瀏覽器最後寫入的一整套金鑰與 AI 設定為準。金鑰不會包含在設定匯出檔案中，也不會傳送給開發者。

同步閱讀佇列時，瀏覽器帳戶同步最多儲存最近 40 筆標題、網址、來源與加入時間；同步待辦時儲存文字、完成狀態與時間；同步天氣城市時儲存顯示名稱、行政區、提供者標記與座標，但不儲存天氣回應；同步自選股票時最多儲存 12 個股票代碼；同步倒數日時最多儲存 20 個事項的 ID、名稱與目標日期。五個開關均預設關閉。關閉某項會刪除其瀏覽器帳戶同步副本並保留本機內容。Ampira 使用逐筆版本與最多保留 30 天的刪除標記合併裝置間修改，開發者無法存取這些瀏覽器帳戶同步內容。清除生成內容快取或重設介面偏好不會刪除待辦事項。

公共來源（Ampira）預設開啟，用於在書籤來源之外補充公開資訊，使用者可在設定中關閉。首次授權公共來源時，Ampira 會一次列出目前介面語言包的所需的精確來源網域（同一網域只申請一次）：14 個同語言來源無需設定 AI 即可讀取，另有 3 個預留的跨語言重大新聞來源。預留來源僅在內建 AI 完整設定或「將整理交給 Bot」已啟用後讀取，且仍需對應網站授權。跨語言項目只有在標題與摘要成功轉換並驗證為目前介面語言後才會顯示；缺少有效本地化結果時，原始外語內容會保持隱藏；有效的 Bot 摘要不依賴內建 AI 金鑰。若已授權頁面宣告另一網域的 Feed，Ampira 只會記錄並顯示待授權網域，直到使用者再次點擊授權才會連線。

靈感來源可在「靈感預設（Ampira）」與使用者原有的書籤資料夾之間單選切換；切換不會建立、修改或刪除瀏覽器書籤，並會保留已選的個人資料夾。預設包含 48 個公開 HTTPS 連結和 24 張隨擴充功能打包的原創封面。預設封面不會請求遠端圖片，預設連結也不會自動加入網站來源權限。使用者主動開啟站內閱讀時，Ampira 會先依網站公開的 CORS 規則嘗試讀取；只有網站不允許這種讀取時，才提供依單個精確網域授權並重試。AI 功能仍只在使用者明確操作後按需申請對應網域。

對於遠端圖片，Ampira 只會在使用者授權對應的精確網站網域後讀取公開頁面的惰性中繼資料。已授權 Feed 項目沒有可用圖片時，Ampira 可限量讀取嚴格同源文章頁面前 1 MiB 的圖片中繼資料，不會連線至其他文章來源，也不會執行頁面指令碼。資訊卡片會依序嘗試 Feed 與原網站圖片候選；個人書籤模式下的靈感卡片會依序嘗試最多三個原網站候選，並在首次呈現前為三批「換一換」開始預先載入。只有沒有可用原圖或全部原圖載入失敗時，使用者另行啟用的「全網圖片搜尋」才會使用 Brave 尋找替代圖片；預設封面與閱讀器圖片不使用 Brave。

研究搜尋的兩個範圍均預設關閉且不會保存。使用者可針對某一輪主動選取一個書籤資料夾進行定向研究、開啟目前 AI 服務商支援的原生聯網搜尋，或同時啟用兩者。Ampira 只會在定向研究時讀取所選資料夾的書籤中繼資料；書籤標題與網址只用於建立候選索引，不能直接成為回答證據。即時讀取網站 Feed 或文章仍需使用者逐一授予精確來源權限。研究快取只保存從 Feed 或 Reader 讀到的少量正文片段及其標題、網址、來源身分、發布日期與擷取時間，不保存另行擷取的全文，並依 30 天、2,000 筆或約 6 MiB 中先達到的限制清理。聯網答案與來源只保留在目前頁面工作階段，不會寫入 IndexedDB；開關關閉時不會向 AI 服務商啟用聯網工具。

網路首圖首次載入後會快取在目前裝置，後續開啟頁面優先使用本機副本。圖片請求不攜帶憑證或 Referer，仍遵循瀏覽器的一般圖片載入規則。最多保留一張網路首圖，圖片回應保存在 CacheStorage，占用計入既有約 25 MB、最長 30 天的快取額度，不參與帳號同步或設定匯出。更換網路圖片會替換副本；清除快取、恢復原廠設定或解除安裝擴充功能會刪除副本。

首圖也支援使用者提供的 HTTPS 影片直連。影片由瀏覽器直接向所選網站載入，靜音循環播放；切到背景或開啟減少動態效果時暫停，播放失敗時恢復預設背景。影片請求不攜帶網站憑證或 Referer，伺服器需允許跨來源播放；網站仍會收到 IP 位址等一般網路資訊。影片不會寫入 Ampira 的圖片快取、帳號同步或匯出檔案；連結與類型按一般外觀設定儲存、同步和匯出。

第三方傳輸

未經使用者操作，Ampira 不會向開發者或第三方傳送書籤、閱讀狀態或搜尋問題。使用者主動開啟站內閱讀時，擴充功能會先直接連線至對應公開網站，以不含憑證與 Referer 的一般 CORS 請求嘗試讀取正文；若瀏覽器阻止讀取，可再傳送一次不讀取內容且不含憑證的 HEAD 請求，以區分網站無法連線與需要授權。公開讀取成功時不申請網站權限，也不寫入依賴權限的 Reader 快取。介面卡片或閱讀器顯示遠端圖片時，瀏覽器會直接請求圖片所在網站；即使不傳送來源頁資訊，該網站仍會收到請求所需的一般網路資訊，例如 IP 位址與瀏覽器資訊。Ampira 不代理這些請求。

使用者明確啟用 AI 後，提交的問題、最多十二輪對話內容、文章標題、摘要、選取的正文、提供上下文所需的文章網址，以及本輪選取的研究證據（標題、摘錄與網址）會傳送給使用者設定的 AI 服務商。如果公共來源的初始授權已包含跨語言來源，其 Feed 標題、摘要與文章網址會在使用內建整理且 AI 完整設定後自動傳送給該服務商，用於轉換為目前介面語言；這是跨語言項目進入資訊流、簡報與搜尋前的必要步驟。依功能路徑與擴充功能版本，文章網址可能是來源中儲存的網址，也可能是移除非必要資訊後的正規化或最小化網址；網址仍可能包含路徑或查詢資訊，應視為已傳輸資料。AI API 金鑰會隨請求直接傳送給使用者設定的服務商，僅供該服務商驗證請求，不會傳送給 Ampira 開發者。

使用者主動開啟對話中的聯網搜尋後，查詢會傳送給其已設定的 AI 服務商並啟用該服務商的原生搜尋工具；是否可用取決於服務商、介面與模型。選用的 Brave 圖片搜尋 API 金鑰只用於使用者另行啟用的缺圖替換。聯網搜尋不會退回瀏覽器的預設搜尋服務。以上第三方傳輸均使用 HTTPS；HTTP 僅允許連接使用者設定的本機 localhost 服務。

導覽列搜尋按鈕開啟同一建議清單，搜尋 Ampira 內容與全部瀏覽器收藏。瀏覽記錄搜尋預設關閉；使用者在「設定 → 瀏覽器」或建議清單主動啟用選用的 history 權限後，擴充功能依輸入的關鍵字查詢瀏覽器保留的歷史，每次最多 200 筆候選，僅顯示符合項目，不蒐集背景造訪、不修改歷史、不儲存副本、不同步，也不傳送歷史結果給開發者、AI 服務商或本機 Bot。撤銷權限或刪除歷史後，相關搜尋結果立即失效。恢復原廠設定會撤銷此權限，不刪除瀏覽器原始歷史。使用者主動選擇網頁搜尋時，查詢會透過瀏覽器內建搜尋介面傳送給預設搜尋服務商，並在發起請求的 Ampira 分頁顯示結果；Ampira 不儲存查詢。網址直達與一般收藏、歷史結果在新分頁開啟。

使用者在天氣卡片提交城市後，Ampira 才會申請 Open-Meteo 的地理編碼 API和天氣預報 API來源權限。符合中國縣級以上行政區的查詢會優先由擴充功能內建的 GeoNames 衍生索引在本機解析，不會為搜尋傳出；其他城市查詢才會直接傳送給 Open-Meteo 地理編碼 API。使用者明確選擇候選城市後，該城市的經緯度會直接傳送給預報 API。Ampira 不使用瀏覽器定位，開發者無法存取這些查詢、座標或天氣結果。中國地點候選依 CC BY 4.0 署名 GeoNames，天氣資料依 Open-Meteo 的條款與授權署名使用。

使用者透過「股市行情」卡片的新增或授權按鈕操作後，Ampira 才會申請 https://qt.gtimg.cn/* 的精確來源權限，並將自選股票代碼直接傳送給騰訊財經。支援 A 股、港股與美股；頁面可見且顯示行情卡片時每分鐘檢查更新，也可手動重新整理。自選清單預設儲存在本機 IndexedDB，可單獨選擇加入瀏覽器帳號同步；新裝置仍需主動授權行情來源。行情快取始終儲存在本機。自選清單與行情不傳送給 AI、Bot 或開發者。報價顯示市場當地時間，資料可能延遲；網路失敗時會標示快取行情。使用者可在「設定 → 瀏覽器」撤銷該來源權限，停止請求並清除行情快取，自選代碼保留。

倒數日的事項名稱與目標日期預設儲存在本機 IndexedDB，可單獨選擇加入瀏覽器帳號同步；不傳送給 AI、Bot、開發者或其他內容服務。天數依瀏覽器所在時區的本機日期計算；刪除事項或恢復原廠設定可清除對應記錄。

權限

activeTab 只在使用者點擊 Ampira 工具列圖示時暫時讀取目前分頁的標題與網址，用於加入稍後讀；導覽或關閉分頁後存取即撤銷，不提供持續分頁或瀏覽記錄存取。閱讀佇列只在使用者另行開啟其預設關閉的同步開關後進入瀏覽器帳戶同步。bookmarks 用於唯讀整理書籤與使用者主動選取的資料夾研究；Ampira 不會呼叫書籤寫入介面。storage 用於本機設定、快取與使用者選擇加入瀏覽器帳戶同步的內容。alarms 用於每 15 分鐘檢查到期來源。選用的 search 權限只在使用者啟用瀏覽器搜尋後申請，透過瀏覽器內建介面呼叫使用者的預設搜尋服務，可在同一設定中撤銷且不會同步或匯出。選用的 favicon 權限只在使用者點擊啟用後申請，透過瀏覽器內建介面為 Ampira 已顯示的書籤與頁面網址提供網站圖示；它不會授予瀏覽記錄或持續分頁存取權，這些網址也不會傳送給第三方圖示服務；Microsoft Edge 不提供此介面時，Ampira 不會申請此權限並改用打包圖示。網站來源權限與 https://api.search.brave.com/* 同樣只在使用者點擊授權時依精確來源申請。天氣只在使用者提交城市時申請 https://geocoding-api.open-meteo.com/* 與 https://api.open-meteo.com/* 兩個精確來源，可在「設定 →瀏覽器」中分別撤銷；撤銷後停止請求並刪除天氣快取，但保留城市選擇。

分享、出售與保留

Ampira 不出售、分享或將資料用於廣告定位。資訊快取最多保留 30 天並限制為約 25MB；定向研究快取最多保留 30 天、2,000 筆或約 6 MiB；天氣快取在 30 分鐘內直接重用，重新整理失敗時最多回退至 6 小時內的資料。使用者可隨時清除快取，也可在「設定 → 關於 → 設定移轉」恢復原廠，清除本機 Ampira 資料、選用權限以及瀏覽器帳戶同步中的 Ampira 設定和已同步內容。同步刪除會傳播到同一帳號的其他裝置，但不會遠端清除那些裝置獨有的本機資料。解除安裝擴充功能會清除擴充功能本機資料；瀏覽器帳戶同步中的資料仍依瀏覽器的同步規則處理。

Chrome Web Store Limited Use

Ampira 對從 Google API 取得之資訊的使用將遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。Ampira 只會為已揭露的單一用途與面向使用者的功能使用這些資料，不會將其用於個人化廣告、信用評估或資料轉售。Ampira 沒有可供開發者或其人員讀取這些資料的後端。
