数据管理

数据删除

  1. 在“设置 → 关于 → 配置迁移”点击“恢复出厂设置”，会清除本机的 Ampira 设置、API 密钥、授权、本地头图、缓存和用户内容，并撤销可选权限。浏览器账号中同步的 Ampira 设置、稍后读、待办、天气城市、自选股票、倒数日、密钥和 AI 配置副本也会删除。同步删除会影响同一账号的其他设备，但不会远程清除其他设备独有的本机数据。浏览器书签和原始浏览历史不会被修改；可选 history 权限会被撤销，瞬时历史搜索结果会失效。
  2. 在设置的“资讯”页点击“清除缓存”，删除资讯、摘要、搜索缓存和来源质量记录。
  3. 在设置的“AI”页点击“移除密钥”或“移除搜图密钥”，会删除本机对应的密钥。如果密钥同步已开启，其他设备也会同步删除该密钥。
  4. 在 Chrome 的 chrome://extensions 或 Microsoft Edge 的 edge://extensions 卸载 Ampira，会清除扩展 IndexedDB、API 密钥和本机扩展存储。
  5. 只想停止某项同步时，可在“设置 → 浏览器 → 跨设备同步”关闭对应开关。这会删除账号中的该项同步副本，各设备已收到的内容或 AI 设置仍会保留。
  6. Bot 看板：在“设置 → MCP → 连接信息”点击“断开连接”（总开关关闭时也可操作），删除浏览器中的本机地址和配对密钥。要清除缓存和发送记录，可切回标准模式后恢复出厂设置。辅助服务保存的看板、留言与去重记录需先停止服务，再单独删除其数据目录（默认为用户主目录下的 .ampira-mcp）。AI 客户端中的 MCP 配置和任务也需单独移除或停止。

Ampira 没有开发者账号或服务器，因此不存在需要向开发者申请删除的云端用户数据库。
