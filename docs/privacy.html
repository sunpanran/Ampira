数据与隐私

Ampira 隐私政策

生效日期：2026-11-08

Ampira 的单一用途是把灵感预设（Ampira）、用户选择的浏览器书签和资讯来源整理成可搜索的新标签页信息看板。Ampira 没有开发者服务器、账号系统、广告或分析。

可选 AI 助手看板

AI 助手看板可分别选择今日简报、资讯整理和 AI 问答，未勾选项使用原有 AI 设置。天气、待办、资讯采集与排序、事件和灵感由插件处理；仅为所选功能提交新的助手任务。插件可向本机服务发送有界的已授权资讯候选，或用户主动提问匹配的资料摘录及来源；明确请求的文章链接也可在已有网站权限内提取。不会自动上传整棵书签树、浏览记录或其他 AI 应用的聊天历史。简报按日期和证据复用，问题只附同一会话的有限近期内容。辅助服务保存有界任务、已发送问题与对应资料。默认不启动模型；用户在本机明确启用 Codex 自动执行器后，排队中的简报与问题会通过当前登录的 Codex 账户自动生成并写回，消耗该账户用量。任务资料会交给 Codex，临时结果文件在运行结束后清理；失败或中断后需主动重试。扩展不会读取 Codex 登录凭据或其他聊天历史。

“接管内容”中的“资讯整理”默认不勾选，仅在 MCP 与 AI 助手看板已开启时生效。开启后，自动、批量和单条资讯整理（含外文翻译）将已授权缓存中的标题与最多 2,000 字符摘录按每批最多五条发送给本机服务，供已授权 AI 助手处理；不发送 API 密钥、书签树或浏览历史。验证后的摘要在本机按原文和语言复用。等待或失败时不自动切换内置 AI。辅助服务保存有界整理任务；配置了本机执行器时会使用其账户用量自动处理。

MCP 总开关、AI 助手看板与接管选项分别保存，修改即时生效。开启总开关或点击“复制接入指令”时，从用户操作请求 http://127.0.0.1/* 可选权限。指令包含十分钟有效的一次性配对码及扩展标识，由用户主动交给可执行本机命令的 AI。长期配对密钥由本机服务与扩展直接交换，不包含在指令、命令输出或普通设置响应中；页面不提供手动密钥表单。

关闭总开关保留模式及配对；连接信息可只读查看服务地址，并可在总开关关闭时断开浏览器配对。这些操作不会删除已发送内容、停止独立辅助服务或停止外部助手任务。来源权限变化会阻止不再授权的内容显示，但无法撤回已进入外部 AI 会话的材料。

配对密钥保存在当前浏览器的 chrome.storage.local 与辅助服务的本机数据目录，不参与同步或导出。浏览器缓存按服务地址与看板身份隔离。辅助服务只监听 127.0.0.1，校验 Host、Origin 与配对密钥，默认将看板、留言和去重记录保存在用户主目录的 .ampira-mcp，不额外加密。已授权 AI 客户端可能按配置将 MCP 内容传给模型提供商；开发者不会接收这些数据。断开连接、恢复出厂或卸载扩展不会删除辅助服务的数据目录，需停止服务后单独处理。

处理的数据

  • 用户选择的书签标题、网址与文件夹结构。
  • 用户授权来源的公开 Feed、网页标题、摘要、正文，以及灵感页封面元数据和图片地址。
  • 界面设置、阅读队列、归档、来源偏好、缓存和搜索问题；用户通过工具栏或 Ampira 卡片明确加入稍后读的页面标题和网址会保存在阅读队列中。
  • 用户输入的待办事项，以及用户手动选择的天气城市、行政区、国家和坐标。
  • 用户自愿配置的 AI 密钥或可选的 Brave 图片搜索 API 密钥。

用途和存储

默认头图使用 Unsplash（images.unsplash.com）的网络图片，沿用下述网络头图加载与缓存规则。显示时图片网站会收到 IP 地址等一般网络信息；用户可在外观设置中更换或关闭头图。

Ampira 使用 chrome.storage.sync 保存部分非凭据设置；如果用户开启浏览器账户同步，浏览器可能把这些设置复制到同一账号登录的其他兼容浏览器安装。阅读队列、待办事项、所选天气城市、自选股票和倒数日默认仅保存在扩展 IndexedDB；用户可在“设置 →浏览器 → 跨设备同步”中分别选择加入同步。资讯、摘要、搜索缓存、完整阅读状态、实用卡模式和天气响应缓存始终保存在本地。用户选择的本地头图会在浏览器内移除原文件元数据并优化为 WebP，只保存在当前浏览器配置的 chrome.storage.local 中，不参与浏览器账户同步或设置导出；移除、替换或卸载扩展会清除对应本地副本。API 密钥与 AI 服务配置默认保存在当前浏览器配置的 chrome.storage.local 中，保存后页面不会回显完整密钥。

“同步 API 密钥和 AI 配置”默认关闭，需要单独开启；“同步个人内容”不会开启密钥同步。开启后，AI 和 Brave 图片搜索密钥会与 AI 服务地址、协议、模型一起保存到浏览器账号的同步存储（chrome.storage.sync）。Ampira 不额外加密，也不设置同步密码。各设备需登录同一浏览器账号并开启扩展同步；新设备仍需同意 AI 数据传输，并授权访问服务网站。

关闭密钥同步或恢复出厂设置，会删除账号中的同步副本，其他设备已收到的本机配置仍会保留。如果在同步开启时移除某个密钥，其他设备也会同步删除该密钥。同时在多台设备修改时，以浏览器最后写入的一整套密钥和 AI 配置为准。密钥不会包含在配置导出文件中，也不会发送给开发者。

同步阅读队列时，浏览器账户同步最多保存最近 40 条标题、网址、来源和加入时间；同步待办时保存文字、完成状态和时间；同步天气城市时保存显示名称、行政区、提供方标记和坐标，但不保存天气响应；同步自选股票时最多保存 12 个股票代码；同步倒数日时最多保存 20 个事项的 ID、名称和目标日期。五个开关均默认关闭。关闭某项会删除其浏览器账户同步副本并保留本机内容。Ampira 使用逐条版本与最多保留 30 天的删除标记合并设备间修改，开发者无法访问这些浏览器账户同步内容。清除生成内容缓存或重置界面偏好不会删除待办事项；卸载扩展会清除本地副本，浏览器账户同步副本依浏览器的同步状态和用户开关处理。

公共来源（Ampira）默认开启，用于在书签来源之外补充公开资讯，用户可以在设置中关闭。首次授权公共来源时，Ampira 会一次列出当前界面语言包的所需的精确来源域名（同一域名只申请一次）：14 个同语言来源无需配置 AI 即可读取，另有 3 个预留的跨语言重大新闻来源。预留来源仅在内置 AI 完整配置或“把整理交给 Bot”已启用后读取，且仍需对应网站授权。跨语言条目只有在标题与摘要成功转换并验证为当前界面语言后才会显示；缺少有效本地化结果时，原始外语内容保持隐藏；有效的 Bot 摘要不依赖内置 AI 密钥。若已授权页面声明了另一域名的 Feed，Ampira 只记录并展示待授权域名，直到用户再次点击授权才会连接。

灵感来源可在“灵感预设（Ampira）”和用户原来的书签文件夹之间单选切换；切换不会创建、修改或删除浏览器书签，也会保留用户已选的个人文件夹。预设包含 48 个公开 HTTPS 链接和 24 张随扩展打包的原创封面。预设封面不请求远程图片，预设链接也不会自动加入网站来源权限。用户主动打开站内阅读时，Ampira 先按网站公开的 CORS 规则尝试读取；只有网站不允许这种读取时，才提供按单个精确域名授权并重试。AI 功能仍只在用户明确操作后按需申请对应域名。

对于远程图片，Ampira 只在用户授权对应精确站点域名后读取公开页面中的惰性元数据。已授权 Feed 条目没有可用图片时，Ampira 可限量读取严格同源文章页面前 1 MiB 的图片元数据，不连接其他文章来源，也不执行页面脚本。资讯卡片会依次尝试 Feed 与原站图片候选；个人书签模式下的灵感卡片会依次尝试最多三个原站候选，并在首屏渲染前为三批“换一换”启动预加载。只有没有可用原图或全部原图加载失败时，用户另行启用的“全网图片搜索”才会使用 Brave 查找替代图片；预设封面和阅读器图片不使用 Brave。

研究搜索的两个范围均默认关闭且不持久化。用户可为某一轮主动选择一个书签文件夹做定向研究、开启当前 AI 服务商支持的原生联网搜索，或同时启用两者。Ampira 只在定向研究时读取所选文件夹的书签元数据；书签标题与网址只用于建立候选索引，不能直接成为回答证据。实时读取网站 Feed 或文章仍需要用户逐个授予精确来源权限。研究缓存仅保存从 Feed 或 Reader 读到的少量正文片段及其标题、网址、来源身份、发布日期与抓取时间，不保存另行提取的全文，并按 30 天、2,000 条或约 6 MiB 中先达到的限制清理。联网答案与来源只保留在当前页面会话，不写入 IndexedDB；开关关闭时不会向 AI 服务商启用联网工具。

网络头图首次加载后会缓存在当前设备，后续打开页面优先复用本地副本。图片请求不携带凭据或 Referer，仍遵循浏览器的普通图片加载规则。最多保留一张网络头图，图片响应保存在 CacheStorage，占用计入现有约 25 MB、最长 30 天的缓存预算，不参与账号同步或设置导出。更换网络图片会替换副本；清除缓存、恢复出厂设置或卸载扩展会删除副本。

头图也支持用户提供的 HTTPS 视频直链。视频由浏览器直接向所选网站加载，静音循环播放；切到后台或开启减少动态效果时暂停，播放失败时恢复默认背景。视频请求不携带网站凭据或 Referer，服务器需允许跨域播放；网站仍会收到 IP 地址等一般网络信息。视频不会写入 Ampira 的图片缓存、账号同步或导出文件；链接与类型按普通外观设置保存、同步和导出。

第三方传输

未经用户操作，Ampira 不向开发者或第三方发送书签、阅读状态或搜索问题。用户主动打开站内阅读时，扩展会先直接连接对应公开网站，以无凭据、无 Referer 的普通 CORS 请求尝试读取正文；若浏览器阻止读取，可再发送一次不读取内容的无凭据 HEAD 请求，以区分网站不可达与需要授权。公开读取成功时不申请网站权限，也不写入依赖权限的 Reader 缓存。界面卡片或阅读器显示远程图片时，浏览器会直接请求图片所在网站；即使不发送来源页信息，该网站仍会收到请求必需的常规网络信息，例如 IP 地址和浏览器信息。Ampira 不代理这些请求。

用户明确启用 AI 后，提交的问题、最多十二轮对话上下文、文章标题、摘要、选定正文、提供上下文所需的文章网址，以及本轮选定的研究证据（标题、摘录与网址）会发送给用户配置的 AI 服务商。如果公共来源的初始授权已包含跨语言来源，其 Feed 标题、摘要与文章网址会在使用内置整理且 AI 完整配置后自动发送给该服务商，用于转换为当前界面语言；这是跨语言条目进入资讯流、简报和搜索前的必需步骤。根据功能路径和扩展版本，文章网址可能是来源中保存的网址，也可能是移除不必要信息后的规范化或最小化网址；网址仍可能包含路径或查询信息，应将其视为已传输数据。AI API 密钥会随请求直接发送给用户配置的服务商，仅用于该服务商验证请求，不会发送给 Ampira 开发者。

用户主动开启对话中的联网搜索后，查询会发送给其已配置的 AI 服务商并启用该服务商的原生搜索工具；是否可用取决于服务商、接口与模型。可选的 Brave 图片搜索 API 密钥只用于用户另行启用的缺图替换。联网搜索不会退回浏览器默认搜索。以上第三方传输均使用 HTTPS；HTTP 仅允许连接用户配置的本机 localhost 服务。

导航栏搜索按钮打开同一推荐列表，搜索 Ampira 内容和全部浏览器收藏。浏览记录搜索默认关闭；用户在“设置 → 浏览器”或推荐列表主动开启可选 history 权限后，扩展按输入的关键词查询浏览器当前保留的历史，每次最多 200 条候选，仅显示匹配结果，不采集后台访问、不修改历史、不保存副本、不同步，也不将历史结果发送给开发者、AI 服务商或本机 Bot。撤销权限或删除历史后，相关搜索结果立即失效。恢复出厂设置撤销此权限，不删除浏览器原始历史。用户主动选择网页搜索时，查询通过浏览器内置搜索接口发送给默认搜索服务商，在发起请求的 Ampira 标签页显示结果；Ampira 不保存查询。网址直达和普通收藏、历史结果在新标签页打开。

用户在天气卡中提交城市后，Ampira 才会申请 Open-Meteo 的地理编码接口和天气预报接口来源权限。匹配中国县级以上行政区的查询会优先由扩展内置的 GeoNames 派生索引在本地解析，不会为搜索传出；其他城市查询才会直接发送给 Open-Meteo 地理编码接口。用户明确选择候选城市后，该城市的经纬度会直接发送给天气预报接口。Ampira 不使用浏览器定位，开发者无法访问这些查询、坐标或天气结果。中国地点候选按 CC BY 4.0 署名 GeoNames，天气数据按 Open-Meteo 的条款与许可署名使用。

用户通过“股市行情”卡片的添加或授权按钮操作后，Ampira 才会申请 https://qt.gtimg.cn/* 的精确来源权限，并将自选股票代码直接发送给腾讯财经。支持 A 股、港股和美股；页面可见且显示行情卡片时每分钟检查更新，也可手动刷新。自选列表默认保存在本机 IndexedDB，可单独选择加入浏览器账号同步；新设备仍需主动授权行情来源。行情缓存始终保存在本机。自选列表和行情不发送给 AI、Bot 或开发者。报价显示市场当地时间，数据可能延迟；网络失败时会标明缓存行情。用户可在“设置 → 浏览器”撤销该来源权限，停止请求并清除行情缓存，自选代码保留。

倒数日的事项名称和目标日期默认保存在本机 IndexedDB，可单独选择加入浏览器账号同步；不发送给 AI、Bot、开发者或其他内容服务。天数按浏览器所在时区的本地日期计算；删除事项或恢复出厂设置可清除对应记录。

权限

activeTab 仅在用户点击 Ampira 工具栏图标时临时读取当前标签页的标题和网址，用于加入稍后读；导航或关闭标签页后访问即撤销，不提供持续标签页或浏览历史访问。阅读队列仅在用户另行开启其默认关闭的同步开关后进入浏览器账户同步。bookmarks 用于只读整理书签和用户主动选择的文件夹研究；Ampira 不调用书签写入接口。storage 用于本地设置、缓存及用户选择加入的浏览器账户同步内容。alarms 用于每 15 分钟检查到期来源。可选的 search 权限只在用户启用浏览器搜索后申请，通过浏览器内置接口调用用户的默认搜索服务，可在同一设置中撤销且不会同步或导出。可选的 favicon 权限只在用户点击启用后申请，通过浏览器内置接口为 Ampira 已显示的书签与页面网址提供网站图标；它不授予浏览历史或持续标签页访问权，这些网址也不会发送给第三方图标服务；Microsoft Edge 不提供该接口时，Ampira 不申请此权限并改用打包图标。网站来源权限及 https://api.search.brave.com/* 同样只在用户点击授权时按精确来源申请。天气仅在用户提交城市时申请 https://geocoding-api.open-meteo.com/* 与 https://api.open-meteo.com/* 两个精确来源，可在“设置 →浏览器”中分别撤销；撤销后停止请求并删除天气缓存，但保留城市选择。

共享、出售与保留

Ampira 不出售、共享或将数据用于广告定位。资讯缓存最多保留 30 天并限制为约 25MB；定向研究缓存最多保留 30 天、2,000 条或约 6 MiB；天气缓存 30 分钟内直接复用，刷新失败时最多回退到 6 小时内的数据。用户可以随时清除缓存，也可在“设置 → 关于 → 配置迁移”恢复出厂，清除本机 Ampira 数据、可选权限以及浏览器账户同步中的 Ampira 设置和已同步内容。同步删除会传播到同一账号的其他设备，但不会远程清除那些设备独有的本机数据。卸载扩展会清除扩展本地数据；浏览器账户同步中的数据仍按浏览器的同步规则处理。

Chrome Web Store Limited Use

Ampira 对从 Google API 获取的信息的使用将遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。Ampira 只为已披露的单一用途和面向用户的功能使用这些数据，不将其用于个性化广告、信用评估或数据转售。Ampira 没有可供开发者或其人员读取这些数据的后端。
